# shop-local-bag — releases

Public APK downloads for the **shop-local-bag** app. The application source
lives in a private repository; only the built APK is published here so the
app's in-app updater can check for and download new versions without needing
any credentials.

**Latest APK:** https://github.com/noamshn/shop-local-bag-releases/releases/latest

Each build is signed with the same release key, so installing a new APK
updates the existing app instead of conflicting with it.
